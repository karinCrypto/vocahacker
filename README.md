# VocaHacker

영어 시험 단어와 커리어 영어 단어를 게임으로 매일 외우는 웹 서비스입니다.
설치나 회원가입 없이 브라우저에서 바로 쓸 수 있고, PC와 모바일 모두 지원합니다.

### 👉 [vocahacker.vercel.app](https://vocahacker.vercel.app) 에서 바로 시작하기

## 이런 분께 추천해요

- TOEIC, IELTS, TOEFL, TEPS를 준비하는 분
- OPIc이나 OPI 회화 시험을 준비하는 분
- 회사에서 쓰는 영어 표현을 익히고 싶은 PM·마케터, 개발자, 디자이너

## 단어장

| 분류 | 단어장 |
| --- | --- |
| 옥스퍼드 사전영어 3000개 | A1 입문, A2 초급, B1 중급, B2 중상급 |
| 시험 | TOEIC, TOEIC 1회차, IELTS, TOEFL, TEPS |
| 회화 | OPIc AL, OPI |
| 표현 | 숙어, 구동사 |
| 직군 | PM·마케터, 개발자, 디자이너 |

옥스퍼드 사전영어 3000개(Oxford 3000)를 포함해 약 5,800개 단어가 준비되어 있고, 외우고 싶은 단어를 직접 붙여 넣어 나만의 단어장을 만들 수도 있습니다.

```
negotiate, 협상하다
deadline, 마감
```

## 게임 4가지

| 게임 | 방법 |
| --- | --- |
| ✎ PAPER QUIZ | 영어를 보고 뜻을, 뜻을 보고 영어를 번갈아 써 보기 |
| 🍄 MARIO BASKET | 떨어지는 단어 중 뜻에 맞는 단어를 바구니로 받기 |
| 🔤 ALPHA MARIO | 알파벳을 하나씩 받아 단어 완성하기 |
| ▦ WORD SUDOKU | 3×3 격자에서 단어와 뜻 짝 맞추기 |

## 사용 방법

1. [vocahacker.vercel.app](https://vocahacker.vercel.app)에 들어갑니다.
2. 단어장을 고르거나 외울 단어를 붙여 넣고, 하루 목표 개수를 정합니다.
3. 게임을 골라 플레이합니다.
4. 게임이 끝나면 맞힌 단어와 틀린 단어를 확인하고, 실제로 아는지 모르는지 직접 고쳐서 저장할 수 있습니다.
5. 다음 날 다시 들어오면 복습할 단어가 자동으로 나옵니다.

## 꾸준히 하게 만드는 장치

- **자동 복습:** 맞힌 단어는 1일, 3일, 7일, 14일, 30일, 60일 뒤에 다시 나와서 오래 기억하게 도와줍니다.
- **행성 탐험:** 외운 단어가 늘어날 때마다 새 행성이 열리고, 400개를 넘기면 마지막 행성 ELYSIUM에 도착합니다.
- **북마크:** 헷갈리는 단어는 따로 모아 복습할 수 있습니다.
- **리더보드와 라이트 모드**도 지원합니다.

## 개인정보

학습 기록은 쓰고 있는 브라우저에만 저장되고, 서버로 보내지 않습니다.
그래서 다른 기기나 다른 브라우저에서는 기록이 이어지지 않습니다.
